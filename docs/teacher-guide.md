# Teacher Quick Guide — 3D Virtual Classroom

> **Draft.** Written from the code before the first live test. It will be checked and updated during the pilot (Gate 3).
> Button names are shown as **English / Filipino**.

## Before class (5 minutes)

1. **Slides → PDF.** In PowerPoint: *File → Save As → PDF*. In Google Slides: *File → Download → PDF*. In Canva: *Share → Download → PDF*. Keep it **under 20 MB**, because learners on mobile data download it.
2. **Open the room 5 minutes early** from a laptop with a good connection, so you're in the room before the learners and their downloads don't all start at once.
3. Check that you see the shield **Teacher / Guro** button in the bottom toolbar. If it's missing, ask the admin to promote you to moderator.

## Starting class

| To… | Do this |
| :--- | :--- |
| Show slides | Drag the PDF into the room (or **Place / Maglagay → Upload / Mag-upload**). Move it to the screen behind the podium, then open its menu and choose **Pin / I-pin**. |
| Change slides | Hover over the PDF and use the **‹ ›** buttons. Everyone sees the same page. |
| Start the lesson | **Teacher → Start Lecture Mode / Simulan ang Lecture Mode**. Learners are muted, can't chat or add objects, and are seated and locked. This also saves their mobile data. |
| Be heard everywhere | Stand on the **podium**. The podium microphone plays your voice through the room speakers, and only teachers are picked up. |

## During class

| To… | Do this |
| :--- | :--- |
| See who wants to talk | **Teacher → Raised hands / Nakataas na kamay**, in the order the hands went up. |
| Let one learner speak | End Lecture Mode briefly, or switch **Learners can talk / Puwedeng magsalita** on, call the learner by name, then switch it off again. |
| Quiet everyone | **Mute all / I-mute lahat** |
| Bring everyone back | **Gather to seats / Paupuin sa upuan**, or **Gather to podium / Tipunin sa podium** |
| Group work | End Lecture Mode. Learners walk to the 4 **pods**, and pods can't hear each other. Use **Gather to seats** to bring them back. |
| Remove someone disruptive | **People / Mga Tao → name → Kick / Paalisin** |

## Ending class

1. **End Lecture Mode / Tapusin ang Lecture Mode** (or leave it on if the next class starts in Lecture Mode).
2. Remove or unpin the slides.
3. Leave the room.

## Rules learners see before joining

Use your first name or a nickname only · don't take or share screenshots or recordings of classmates · be kind, raise your hand to speak.
**The platform does not record anything.** Don't record the class yourself without written parent consent (school DPO policy).

## If something goes wrong

| Problem | Try |
| :--- | :--- |
| A learner can't hear anyone | Ask them to tap anywhere in the room (browsers pause audio until you tap). |
| A phone is slow or hot | Ask them to rejoin with **Lite mode** switched on (on the join screen). |
| A learner can't connect at all | Send them the device check page: `https://ben010618.github.io/classroom-platform/`. They copy the result to the ICT coordinator. |
| Your Teacher button is missing | You aren't a moderator in this room: ask the admin. |
